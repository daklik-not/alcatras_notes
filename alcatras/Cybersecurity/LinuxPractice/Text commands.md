# Vim

## Основные команды

### Навигация

vim

h    " влево
j    " вниз
k    " вверх
l    " вправо
### Режимы
vi
Esc     " возврат в нормальный режим
i       " переход в режим вставки
a       " вставка после курсора
o       " новая строка ниже + режим вставки
O       " новая строка выше + режим вставки
R       " режим замены
### Работа с текстом
#### Копирование
vim
yw      " скопировать слово
yy      " скопировать строку
#### Удаление
vim
dw      " удалить слово
d$      " удалить до конца строки
dd      " удалить строку
x       " удалить символ
ce      " удалить до конца слова + режим вставки
cc      " удалить всю строку + режим вставки
c[n]w   " удалить n слов + режим вставки
#### Отмена действий
vim
u       " отменить последнее действие
Ctrl+R  " вернуть отмененное
### Поиск и замена
vim
/word       " поиск слова
n           " следующее совпадение
N           " предыдущее совпадение
?word       " поиск в обратном направлении
:s/old/new  " замена первого вхождения в строке
:s/old/new/g " замена всех вхождений в строке
:%s/old/new/g " замена по всему файлу
### Настройки поиска
vim
:set ic      " поиск без учета регистра
:set noic    " отключить поиск без учета регистра
:set hls     " подсветка результатов поиска
### Навигация по файлу
vim
Ctrl+G  " показать позицию в файле
%       " найти matching bracket
[number]G " перейти на указанную строку
0       " перейти в начало строки
$       " перейти в конец строки
### Внешние команды
vim
:!command  " выполнить внешнюю команду
:w filename " сохранить файл
:r filename " вставить содержимое файла
### Работа с выделением
vim
v       " начать визуальное выделение
:w      " сохранить выделение в файл (после выделения)
### Важные примечания

- Все команды работают только в английской раскладке
    
- При удалении текст сохраняется в буфер (для вставки используйте `p`)
    
- Команды можно комбинировать с числами (например `d2w` - удалить 2 слова)
    
- Операторы (d, c, y) можно комбинировать с движениями (w, e, $)
