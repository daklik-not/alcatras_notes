ssh - позволяет подключиться к другому компьютеру по сети и удаленно от него работать в его командной строке. Вся передаваемая информация шифруется.

``ssh [опции] [пользователь]@[хост]```

Если имя пользователя на удаленной машине и локальной совпадают, имя можно опустить
**Флаги**:
```
-p : порт для подключения
-i : файл ключа (пример: ssh -i ~/.ssh/my_custom_key user@example.com)
-X : позволяет запускать графические приложения с удаленного сервера, а их результат будет у вас на экране.
-L : создать туннель для переброса порта (ssh -L 3333:localhost:5432 user@example.com переброс с порта 3333 на моем устройстве на 5432 на сервере)
-R : пробрасывает порт с удаленного устройства на мое(ssh -R 8080:localhost:3000 user@example.com)
-v/-vv : режим подробного вывода
-C : сжатие данных
-f : перевести в фоновый режим ssh
-N : не выполнять никакую команду после подключения
-t : принудительное выделение pseudo terminal; нужен когда команде требуется интерактивный терминал.
```

Можно создать конфиг, чтобы все флаги сразу же проставлялись. Можно задать свой SSH-ключ, тогда если сервер его примет не надо будет вводить пароль
