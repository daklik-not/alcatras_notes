Работа с файлами
ls - просмотр содержимого папки(использовать с флагом -l + флаг -a выводит скрытые файлы) Для ls -l есть псевдоним ll -a. ls -r выведет рекурсивно все содержимое папки
cd - переходит в нужную директорию
cat - выводит содержимое файла + используется для конкантенации(cat > new_file.txt)
file - возвращает разрешение файла
du - оценивает и выводит размер файлов и директорий(юзать с флагом -sh)
find (директория) (критерии) (действие) - ищет файл в текущей директории и ее поддиректориях
touch - создает файл
echo - просто выводит на экран текст, аналог cout
mkdir - создает директорию c флагом -p можно создать сразу целую иерархию папок вроде /s1/s2/s3
cp f1 f2 - комирует f1 в f2
cp -r test1 test2 -позволяет копирует директории, флаг нужен чтобы рекурсивно скопировалось все содержимоег
rm -r рекурсивно удаляет директорию и все ее содержимое. Важно заметить, что удаляя файлы через директорию, нет возможности их восстановления -f удаляет даже защищенные фалйы и каталоги без подтвержденияя
mv dir1/oldfile dir2/newfile - перемещение файла и его переименование 
man ssh - выводит полное описание комнады конкретно здесь это ssh
chmod - я его не изучал особо, но это предоставление прав на что-то, конкретно здесь предоставление прав на выполнение (+x)4
grep "smth" file - поиск подстроки в файле. Есть флаги, например grep -w вернет только полные совпадения
ln original_file linkfile - создает жесткую ссылку на файл или директорию. Можно создать символическую ссылку, используя флаг -s;
less - нормальное представление текстового документa
alias/unalias - создание и удаление псевдонимов синтаксис : alias newname="ls -la". Такие псевдонимы не сохраняются после перезагрузки. Можно добавить здесь - ~/.bashrc
Код
gcc -o main main.c - компиляция файла в бинарный
g++ -o main main.cpp - на c++
wine main.exe выполнение exe файла

**Работа со спец-символами**
Лучше всего завершить флаги (--) и далее просто взять в кавычки. Пробелы фиксятся только кавычками. Вообще для спец символов есть экранирование ( \ );
При выполнение команда поиска здесь так же работают регулярные выражения:
\* 1 или несколько символов
\? 1 символ
[] - любой символ в скобках
