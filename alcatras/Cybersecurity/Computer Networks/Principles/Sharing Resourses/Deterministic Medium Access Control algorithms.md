### Deterministic Medium Access Control algorithms[¶](https://beta.computer-networking.info/syllabus/default/principles/sharing.html#deterministic-medium-access-control-algorithms "Permalink to this headline")
Ни один из вышеописанных алгоритмов не гарантирует, что кадр будет доставлен в заданное время.
***Token ring network***
Набор станций, который связаны однонаправленным кольцом. Обмениваются токенами(маленький кадр, который авторизует передачу по кольцу) и кадрами. Когда Token ring запускается одна из станций отправляет токен. Чтобы передать кадр, станция убирает токен с сети. Важно - токен общий для всех. Если станция получила токен - она имеет право передавать

Интерфейсы оперируют в режиме *listening* и *transmission*. Когда они слушают, они принимают электрический сигнал, delay, передача дальше по кольцу
Первая проблема - токен должен перемещаться по кольцу, пока другие кадры не передаются. На картинке формат токена - начало кадра, флаги в acces control, конец. В том числе среди флагов есть Token Bit, который установлен в 1.

Теперь о самой проблема. Допустим, что на рисунке отправляется токен из S1. В таком случае первый отправленный бит токена вернется на станцию, когда отправились еще только 5 бит токена. Для этого есть специальная станция *Monitor* в которой задержка равна как минимум времени передачи 24бит(размеру токена).
*Передача кадров*
Когда станция получает токен, если это ее токен она может отправить свой кадр. Когда она получает кадр, то она должна просто переслать его соседу по кольцу.
Есть проблема - мы не можем отличить делиметр кадра от делиметра токена. Оно решается довольно просто - если станция отправила делиметр токена, то она отправляет свой кадр не с начала, а после делиметра. Непрерывность обеспечивается как раз засчет задержки в 1 бит.
После передачи кадра, станция остается в режиме передачи до того момента, пока не получит последний бит собственнного кадра.
Очевидно, что реальная сеть намного сложней. Например при инициализации станции должны договориться, кто будет монитором. Выбранная станция отправляет токен. Ни одна станция не может держать токен больше чем *THT* секунд. Монитор должен получать *N \* THT* секунд  токен, иначе он обрезает сеть и реинициализирует ее.
