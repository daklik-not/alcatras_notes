Иногда несколько TL может быть запущено на 1 сетевом уровне. В таком случае сетевой уровень мультиплексирует сегменты для разных протоколов и в заголовке пакета указывает тип протокола.
Люди взаимодействуют с адресами используя имена - символьные строки. Использование имен в качестве псевдонимов часто используется в CS - например имена переменных. Адреса под именами могут меняться
Изначально использовался файл hosts.txt - он находился на каждом устройстве и тупо содержал список имен. Очевидно, что дальше пришли к иерархичной структуре - ![[Pasted image 20260304010857.png]]
***BNF допустимых имен***
```c
domain ::= subdomain | " "
subdomain ::= label | subdomain "." label
label ::= letter [ [ ldh-str ] let-dig ]
ldh-str ::= let-dig-hyp | let-dig-hyp ldh-str
let-dig-hyp ::= let-dig | "-"
let-dig ::= letter | digit
letter ::= any one of the 52 alphabetic characters A through Z in upper case and a through z in lower case
digit ::= any one of the ten digits 0 through 9
```

#### DNS  - Domain Name System
DNS - распределенная база данных, которая содержит сопоставление  между именами и адресами. Используется client-server схема. Каждый *nameserver* хранит части распределенной базы данных и отвечает на запросы, как на картинке - 
![[Pasted image 20260304013018.png]]
Чтобы найти нужный адрес для h3.a.sdom1.dom, DNS клиент сначала посылает запрос на nameserver, который отвечает за главный домен .dom. Главный сервер возвращает сервер, который отвечает за sdom1.dom домен. Клиент сам обращается поочереди к каждому серверу собирая таким образом реальный адрес. Ну и есть специальный root nameserver.
Каждый корневой nameserver содержит домены верхнего уровня(типо .dom - то что в самом конце).
Очевидно, что каждый DNS клиент должен хранить адреса root name-серверов.  Для этого в сети находится несколько серверов *DNS резолверы*. Сеть обычно содержит несколько резолверов. Каждый хост в этой сети сконфигурирован отправлять все DNS запросы на эти локальные резолверы. Далее уже resolver посылает на root или top домен. В таком случае клиенту не надо вручную отправлять каждый DNS запрос.
