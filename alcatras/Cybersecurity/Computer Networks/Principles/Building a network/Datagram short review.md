*Hop-hop forwarding(пошаговая пересылка)*.
Когда роутер получает пакет, который ему не принадлежит, он ищет адрес назначения в *forwarding table - таблица пересылки*. Эта таблица сопоставляет адрес назначения с сетевым интерфейсом роутера, по которому пакет будет перенаправлен. Она используется при получении каждого пакета.

Путь определен, как список всех роутеров посредников. Путь может быть выведен, через таблицу пересылки роутера, чтобы определить следующий роутер на пути. В сети с корректными таблицами источник-назначение содержит фиксированное число промежуточных роутеров.

Алгоритмы составления таблицы составляются либо централизованно, либо местно

*Black hole*
Это роутер, который получает пакеты для хотя бы одной пары источник-назначение, но у него нет вхождения для этого адреса.  Задача алгоритма не допускать таких дыр

*Циклы*
Если случайно путь зациклился - очевидно то же проблема. Она еще хуже потому что понижается реальная пропускная способность.

В сети гарантированно не  должно быть не циклов, не черных дыр - из каждого хоста можно обратиться к каждому.
