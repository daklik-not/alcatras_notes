### Control Plane  - Плоскость Управления
Вычисление таблиц пересылок - часть плоскости управления. Распределенные алгоритмы, которые этим занимаются являются частью плоскости управления. Есть 2 типа протоколов маршрутизации - *distance vector routing и link state routing*
Одна из целей плоскости управления - высчитывание *таблиц маршрутизации*. Таблица маршрутизации хранит адрес назначения, интерфейс, по которому надо отправить, адрес следующего роутера, стоимости пути. Вообще информация зависит от реализации таблицы маршрутизации.
___
Почитать чем таблица пересылок отличается от таблицы маршрутизации можно вот здесь:
[What is the difference between routing table and forwarding table? - Network Engineering Stack Exchange](https://networkengineering.stackexchange.com/questions/52150/what-is-the-difference-between-routing-table-and-forwarding-table)
По простому таблица маршрутизации нужна контрольной плоскости для высчитывания пути, который затем помещается в таблицу пересылок. В общем случае таблица пересылок используется для отправления пакета - она быстрее. Посмотреть ее можно через команду - Get-NetRoute
