Чтобы образовалась сеть нужно соединить 2 хоста. Есть разные способы

| Тип передачи         | Описание                                                                                                                                               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Электрический кабель | Витая пара(телефонные сети + сети предприятий)<br> Коаксиальный кабель - (кабельное ТВ)<br>                                                            |
| Оптоволокно          | Публичные сети, сети предприятий. <br>Многомодовый, использует LED, дешевле, несколько километров<br>Одномодовый использует laser, десятки километров. |
| Беспроводные         | радио-сигнал, маленький радиус покрытия. Некоторые используют лазер со светом на удаленный детектор                                                    |
