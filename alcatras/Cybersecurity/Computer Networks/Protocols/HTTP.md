Раньше был протокол ftp. Интернет использовался для удаленного доступа к серверу через терминал - *telnet*. Были *аутентифицированные* пользователи, по логину и паролю, они получали доступ к своей директории, а *анонимные* пользователи получали доступ к публичным папкам. Сейчас для терминального доступа используется ssh протокол - он защищен, шифруется.

Для обмена информацией о ядерных исследованиях была разработана новая система обмена документов - *world wide web*. Гипертекстовый документ - основа - содержит ссылки на другие гипертекстовые документы, к которым немедленно можно получить доступ. Гиперссылки моги ссылаться на документы, расположенные на других машинах. Фактически это начала интернета.

Эта система состояла из 3 важных частей.
1. Стандартизированная схема адресации
2. Стандартный формат документа
3. Протокол для эффективного извлечения документов, сохраненных на сервере

Все стандарты были открытые и реализации веб-сервером и клиентов также.
