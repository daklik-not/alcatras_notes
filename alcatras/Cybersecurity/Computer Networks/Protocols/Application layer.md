### The application layer
Приложения используют транспортный уровень, который в свою очередь подразделяется на *conneciton-less* и *connection-oriented* сервисы.

При использовании connection-less ТУ способен распознавать ошибки, но не будет их чинить. То есть приложение просто не получит данные.
Каждое приложение идентифицируется по хосту и по номеру порта, который слушает SDU.
Есть ipv4 и ipv6 адреса - разница в количестве байт.
