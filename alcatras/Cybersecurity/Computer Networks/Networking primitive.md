Интернет - большо количество соединенных между собою подсетей.
В сети интернет есть публичные, а есть приватные сети.
Публичные - сети, чьи ip адреса уникальные по всему миру. Он используется для идентефикации устройства в сети интернет.
Приватные - сети, чьи ip адреса уникальные внутри этой маленькой сети. Он используется для идентификации этого устройства другим.
Для идентификации устройства в сети используется ip-address и mac-address.
**Ip-address**
Адрес, который используется для идентефикации хоста, на какой-то период времени. Его можно перенести на другое устройство. IP адрес состоит из 4 октетов.  В сети не может быть больше одного IP адреса.  Они следую набору стандартов, который известен, как протоколы.
Они помогают устройствам общаться на 1 языке. В зависимости от того, в какой сети устройство, в публичной или приватной, ему присваивается соответствующий IP адрес.
Публичные IP адреса выдаются провайдером(**ISP - Internet Service Provider**).  Ранее было написано, что используются IP адреса из 4 октетов. Сейчас используются другие ip адреса, формата IPv6.
IPv4 и IPv6 - протокол используемые для присвоения уникальных числовых адресов устройствам в сети и обеспечение их связи.

Такое поведение может нарушить плохо-реализованные защитные системы. Например, если устройство притворится мак адресом админа.

**LAN**
LAN - Local Area Network. Сеть которая соединяет устройства на ограниченной территории.
Основные технологии LAN.
а) **Ethernet**
Набор технологий для проводных LAN. Устройства подключается с помощью кабелей к центральному устройству - коммутатору(**switch**). Коммутатор использует мак-адреса устройств для точной отправки данных нужному устройству.
   **Wi-Fi** 
Беспроводная LAN. Устройства подключается к беспроводной точке доступа(**Wireless Acssess Point**). Она обычно подключена к проводному коммутатору.
б) Критически важные службы:
	**DHCP** - сервер, который автоматически назначает IP адреса всем устройствам в сети. От него при подключении устройство получает все необходимые настройки(IP адрес, маску подсети, адрес шлюза).
	 **DNS** - преобразует понятные человеку имена в удобные для машины IP адреса.
в) Для частых сетей зарезервированы IP адреса, которые не используются в интернете. Например, для дома используются: 192.168.0.0 — 192.168.255.255. Используется маска подсети для определения границ локальной сети, помогает отделить внутренние адреса от внешних. Есть шлюз по умолчанию (**default gateaway**), все запросы в интернет отправляются через него
**Маршрутизатор(router) -** устройство, которое управляет ip адресом. Он прячет все устройства в сети за 1 публичным адресом, который выдает провайдер.
**Шлюз** точка выхода из вашей локальной сети в другие сети. Он знает куда пересылать данные, если он расположен не в вашей сети
**Проброс портов**  - технология, которая позволяет перенаправлять трафик, если он приходит на порт внешнего IP адреса (роутера), сразу же на определенный  порт конкретного устройства.
**Socket** - некая программная абстракция сетевого соединения, которая инкапсулирует в себе информацию сетевого и транспортного уровня соединения - удаленные и свои ip adresa и порта.

**OSI model**
Задача модели OSI в том, чтобы поделить сложный процесс отправки данных на 7 разных уровней. Каждый уровень выполняет только свою функцию и взаимодействует только с соседними. Это позволяет производителям оборудования думать только о том, что происходит на уровне их устройства. Важно заметить, что это не описание временного порядка событий, а описание логических связей между уровнями
Также нужно добавить, что зачастую в реальном интернете, уровни смешиваются, и 1 может выполнять функции другого. Например по Танненбауму уровень представления, сеансовый и прикладной обьединены - TCP/IP.

Вот полная хронология происходящего:
Я отправляю сигнал в мессенджере. Он шифруется. Устанавливается сессия с сервером. Сообщение разбивается на сегменты, к ним добавляется порт. Сегменты упаковываются в пакеты. Пакеты упаковываются в кадры. Кадрый преобразуются в электрический импульс.
Для кибербезопасности:
Физический - кража оборудования, обрыв кабелей.
Канальный - Атака ARP Spoofing (ARP - протокол)
Сетевой - Атаки с подменой IP адреса (IP spoofing)
Транспортный - сканирование портов, SYN флуд.
Прикладной - фишинг, SQL иньекции.

**Таблица маршрутизации**
База данных, которая хранится в памяти маршрутизатора, которая содержит правила, определяющие, куда надо направит сетевой пакет.  Она используется внутри сети провайдера. Содержит следующую информацию:

| Сеть назначения | IP адрес сети ,куда надо доставить пакет                                                                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Маска подсети   | Определяет, какая часть относится к адресу сети, а какая к адресу хоста                                                                                                       |
| Шлюз(Next hop)  | Адрес следующего маршрутизатора, на который необходимо отправить пакет, чтобы он дальше двинулся к своей цели.                                                                |
| Интерфейс       | Порт, через который устройство общается с другими устройствами. Если интерфейс один, его адрес определяет мак адрес устройства. Может быть физический и виртуальный(WAN-порт) |
| Метрика         | Числовое значение, указывающие стоимость или предпочтительность маршрута                                                                                                      |
Сетевой интерфейс - это как бы дверь через которую устройство общается с другим. Например для обычного роутера, есть как минимум 3 сетевых интерфейса - WAN порт, LAN порт, WIFI порт.
Source port
Для определения порядка выполнения и реализации мультиплексирования ОС выдает +++каждому приложению свой порт. Есть уже фиксированные порты, например для http протокола, есть нет. Такой порт называется Source Port
**ARP hash** - на уровне локальной сети устройствав общаются с помощью мак-адресов. Рассмотрим такую ситуацию. На роутер приходит запрос передать пакет такому-то устройству. Однако внутри локальной сети роутер общается используя мак адреса а ему пришел IP адрес. Arp hash - это таблица, вида ip_address - mac_address. Если ip нет в таблице, то с помощью специального протокола рассылается для всех устройств запрос, чей это  ip адрес. Ну и соотвественно он возвращается.

Краткий обзор физического уровня.  
Скорость канала зависит не только от типа провода, а еще от кучи других факторов. Например, от мощности вычислительных узлов, внешних помех и т.д.  
Как аналоговый сигнал переделывается в цифровой. С помощью аналого-цифрового преобразования (АЦП): сигнал дискретизируется (измеряется через равные промежутки времени) и квантуется (каждому измеренному значению присваивается цифровой код). Ряд Фурье используется для анализа сигналов, а не для их преобразования при передаче.  
Есть несколько формул для вычисления пропускной способности канала, например, теорема Найквиста и формула Шеннона.  
Полоса пропускания - разница между самой высокой и самой низкой частотой, которую может передать канал.  
Скорость передачи данных (Битрейт) - то, сколько данных можно передать по каналу за единицу времени.  
Частота сигнала - показывает, как быстро колебания сигнала повторяются.  
Внешние помехи:  
Радиоволны  
Электромагнитное излучение  
Температура  
Cross talk - 1 кабель перехватывет информацию из другого.
Физическое кодирование - преобразование цифрового сигнала в физический для передачи по среде. Есть разные способы кодировок. Например, NRZ - кодирование напряжением (+5В - 1, 0В - 0). Возникает проблема: при большом количестве подряд идущих нулей или единиц приемник и передатчик могут рассинхронизироваться. Для решения этой проблемы придумали схемы, где каждый бит кодируется изменением сигнала — например, Манчестерское кодирование.  
СКС - структурированная кабельная система. Создана для того, чтобы большинство устройств в здании подключалось по стандартным проводам и разъемам. Это унифицирует подключение и избавляет от хаоса проводов, иначе любое помещение выглядело бы как ЦОД.
