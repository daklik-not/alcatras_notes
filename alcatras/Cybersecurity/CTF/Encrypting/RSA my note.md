RSA - алгоритм асинхронного шифрования.  #rsa
**Математическая часть RSA**
**Функция Эйлера**
$\phi(n)$ - считает количество чисел, меньше числа n, для которых будет выполняться 
$$
\begin{cases}
    1 \le k \le n \\
    \gcd(k, n) = 1
\end{cases}
$$Функция Эйлера мультипликативна, а значит: $\phi(mn)$ =$\phi(m)*\phi(n)$
Если есть k чисел, которые друг другу просты, то:
$$\phi(\prod_{i = 1}^{k} m_i) = \prod_{i = 1}^{k} \phi(m_i)$$
Если $m$ и $n$  простые, то $\phi(mn) = \phi(m)*\phi(n) = (m - 1)*(n - 1)$
Это так, потому что для простого числа $n$, функция Эйлера равна $n - 1$
**Теорема Эйлера**
Утверждается, что если $m$ и $n$ попарно простые, то $m^{\phi(n)} \equiv 1 (\mod n)$
Словами - если $m$ и $n$ попарно простые, то число m в степени равной функции Эйлера от n по модулю n  равно 1
**Обратные по модулю числа**
Обратное по модулю целого $a$ , это такое число $x$, что $ax$ сравнимо с 1 по модулю $m$
$ax \equiv 1  (\mod m)$
Обратное число $a$ существует по модулю $m$, если $a$ и $m$ являются взаимно простыми, а именно $\gcd (n, m) =  1$  
Если обратное число $y$ существует, то в пределах от 0 до $n - 1$ существует ровно 1 такое число.
**Lemma 1**
Если $m$ и $n$ попарно простые, то тогда:
$$m^{(k\phi(n) + 1)}\equiv m\mod(n)$$
Доказательства можно почитать здесь [RSA Algorithm - Lei Mao's Log Book](https://leimao.github.io/article/RSA-Algorithm/). Я их разобрал.

**Алгоритм RSA**
E - функция шифрования
D - функция дешифрования
4 базовых требования для криптосистем с публичными ключами:
	$D(E(M)) = M$
	$E(D(M)) = M$
	$E$ и $D$ легко посчитать
	Знание $E$ не дает ничего знать о $D$
**RSA Basic Principle**
$${m^e}^{d} \equiv m \mod n$$
$(n, e)$ - публичный ключ для шифрования
$(n, d)$ - приватный ключ для дешифрования
$!!! 0 < m < n$

**RSA Key Generations**
$$n = p * q $$
где $p, q$ - большие простые числа -> попарно простые.
Тогда по теореме Эйлера - $$m^{\phi(n)} \equiv 1 \mod(n)$$
где $m$ цифровое представление сообщения. Есть момент, что $m$ может быть равно по модудю $q$ или $p$ . В таком случае не выполняется условие для теоремы Эйлера, что $m$ попарно простое с n. 

$$\phi(n) = \phi(pq) = \phi(p)\phi(n) = (p - 1)(q - 1)$$
$$ m^{k\phi(n) + 1} \equiv m \mod(n)$$
Отсюда из базового принципа RSA следует, что $ed=k\phi(n) + 1$.($k$ - любое число).
Заметим, что фактически это эквивалентно следующему $ed \equiv 1 \mod\phi(n)$
Тогда нужное число $d$ существует только тогда, когда $\gcd(e, \phi(n)) = 1$
Тогда при определенном $e$ можно легко вычислить обратное по модулю $d$ с помощью моего любимого расширенного алгоритма Евклида.
**Шифрование и дешифрование сообщение**
Функция шифрования: $c \equiv m^e \mod(n)$. На практике используется следующее
 $$c = m^emodn$$Это работает, потому что $c < n   ->m^emodn < m$
Функция дешифрования в таком случае:$c^d \equiv (m^{ed}) \equiv m \mod n$. Или на практике
$$m = c^d*modn$$
Для взлома лучше всего попытаться посчитать $\phi(n)$ - через факторизацию, однако в реальных условия с обычным не квантовым компом это просто невозможно, так как используется длинная арифметика

**Using CRT with RSA**
Для экспоненты $e$ чаше всего выбирают значение, в битовом представлении которого меньше всего 1.
65537 =  10000000000000001
Чтобы более эффективно считать RSA можно использовать CRT. Полный алгоритм
$dP = e^{-1} \mod(p - 1)$ // число при умножение которого на e даст 1 по модулю p - 1, то есть $dP$ любое число, которое удовлетворяет $dP*e \equiv 1 \mod N$. 
$dQ = e^{-1} \mod (q - 1)$
$qInv = q^{-1} \mod p$
Для того, чтобы посчитать сообщение $m$:
Это называется **PKCS1**:
$m _1 =  c ^{dP} \mod p$
$m_2 = c^{dQ} \mod q$
$h = qInv * (m_1 - m_2) \mod p$
$m = m_2 + hq$
Чтобы обьяснить, то тут написано нужны 2 теоремы из теории чисел -  теорема Эйлера, которая уже есть выше в этой заметке, и Китайская Теорема об Остатках (CRT).
**CRT**
Пусть $p , q$ простые числа и $n = pq$. Тогда для любой пары ($x_1, x_2$), где $x_1 <= p, x_2 <= q$ есть уникальное число $x, такое что:
						$x_1 = x \mod p,$
						$x_2 =  x\mod q$
**Arithmetic in CRT representation**
$m_1 = c ^d \mod p$
$m_2 = c^d \mod q$
Тогда по *CRT* получается $m_1 < p, m_2 < q , p,q - простые$ тогда есть такое число, для которого 
$m_1 = m \mod p$ и $m_2 = m \mod q$ ->  $m = c ^d \mod n$ 
Это нужно для формула Гарнера, которую я здесь доказывать не буду, но доказательство можно в depseek забить, там все понятно относительно.
$m = m_2 + hq$
h = $((m_1 - m_2))((q^{-1} \mod p))\mod p$

Можно еще понизить степень с помощью теоремы Эйлера
$$\Large{c^d =c^{k\phi(p) + d \mod  \phi(p)} = c^{\phi(p)k}*c^{d\mod\phi(p)}}$$


Далее так, как мы ищем $c^{d\mod \phi (p)}$  по лемме:
$$\Large{c^d \equiv c^{d \mod \phi(n)}\equiv c^{d*mod(p - 1)} \mod p}$$
**RSA final calculation**
$d \mod (p - 1) = e^{-1} \mod(p - 1)$, поскольку $d*e \equiv 1 \mod (p - 1)(q - 1)$ 
 По свойству модульной арифметики: $d*e \equiv 1 \mod p - 1$
$d \mod (q - 1) = e^{-1} \mod(q - 1)$
$dP = (e^{-1} \mod (p - 1) ) = d \mod(p - 1)$
$dQ = (e^{-1}\mod(q - 1)) = d\mod(q-1)$
$m_1  = c^{dP}\mod p$
$m_2 = c^{dQ} \mod q$
$qInv = q^{-1}\mod p$
$h = qInv*(m_1-m_2)\mod p$
$m = m_2 + hq$

Вообще это усложнение с dP и dQ нужно для того, чтобы можно было быстрей шифровать и дешифровать. Мы заранее считаем эти значения, и потом уже по упрощенной формуле считаем то, что нам нужно.
