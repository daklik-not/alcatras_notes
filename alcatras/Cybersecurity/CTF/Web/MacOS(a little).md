## macOS-специфичные файлы

| Файл | Описание | Куда смотреть |
|------|----------|---------------|
| **.DS_Store** | Хранит настройки папки, имена файлов | `/.DS_Store`, `/path/.DS_Store` |
| **._*** | AppleDouble (resource forks) | `._index.html`, `._.htaccess`, `._robots.txt` |
| **.localized** | Локализация папки | `/.localized` |
| **Icon\r** | Кастомная иконка (символ возврата каретки) | `/Icon\r` |
