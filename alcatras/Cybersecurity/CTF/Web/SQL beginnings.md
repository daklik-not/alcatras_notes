**Типы баз данных**
**Реляционные**
Грубо говоря, таблички. Отношения между различными таблицами называваются Schema. Можно выбрать какую-то одну колонку, и другую в другой таблтце. Тогда 1 запросом мы можем получиться все данные сразу
**Нереляционные(NoSQL)**
Не таблички. Есть 4 модели не реляционных баз данных: 
	key-value(обычно хранят данные в JSON или XML. Для каждого вхождения есть свой ключ)
	document-based
	wide-column
	graph
Самый типичный пример - MongoDB
