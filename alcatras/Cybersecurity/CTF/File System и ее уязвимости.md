**Файловая система (File System)** — это способ организации и хранения данных на носителях (жёстких дисках, SSD, флешках). Она управляет тем, как данные записываются, читаются и как к ним осуществляется доступ.
Файловая система определяет:
- структуру каталогов (иерархию папок и файлов);
- способы хранения метаданных (права доступа, владельцы, даты);
- типы файлов и их атрибуты;
- допустимые операции (чтение, запись, выполнение).

Файловая система Linux

| Каталог | Назначение                                        |
| ------- | ------------------------------------------------- |
| `/bin`  | \|\|Исполняемые файлы системных утилит\|          |
| `/etc`  | \|\|Конфигурационные файлы\|                      |
| `/tmp`  | \|\|Временные файлы\|                             |
| `/usr`  | \|\|Пользовательские программы и библиотеки\|     |
| `/var`  | \|\|Логи, кэш, почта и прочие изменяемые данные\| |
Основные типы FS в Linux
EXT-family, JFS, XFS, Btrfs, swapa. Под одним деревом могут скрываться разные файловые системы, смонтированные в разные точки. Они обслуживаются разными драйверами. Вообще подробно почитаю про это, как дойду до файловых систем в МОС.

Файловая система Windows.
Начинается с каталогов - C:\\. Каждый диск, отдельная файловая система. Примеры - FAT(FAT16, FAT32). NTFS.

К каждому файлу можно обратиться по HTTP.
Пример: https://example.com/index.html
Когда сервер получает HTTP-запрос, он преобразует путь URL в путь внутри файловой системы. Злоумышленник может изменить путь и получить доступ к файлам вне веб директории.
