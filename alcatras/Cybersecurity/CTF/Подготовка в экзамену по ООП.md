
#### Inline функции
Функции, которые могут автоматически подставляться компилятором. Пример:
```c
inline int square(int x) { return x * x; }

int main() {
    int a = 5;
    int b = square(a);   // Компилятор может заменить на: int b = a * a;
}
```
Методы, которые определены в теле класса по умолчанию *inline*. При этом *inline* это не приказ. Компилятор сам решает что ему делать.

#### Дружественные классы
Дружественные классы имею доступ ко всем приватным полям и методам.
```c
class A {
private:
    int secret;

public:
    A(int s) : secret(s) {}

    // ОБЪЯВЛЕНИЕ ДРУЖЕСТВЕННОГО КЛАССА
    friend class B;   // Теперь класс B имеет доступ ко всем членам A
};
```

#### Дружественные функции
Это функции, которые определены вне класса, но при этом имеют доступ к его приватным полям. Пример:
```c
class Counter {
    int value;  // приватное поле

public:
    explicit Counter(int v) : value(v) {}

    // ОБЪЯВЛЯЕМ ДРУГА: эта функция не член класса, но имеет доступ к private
    friend bool operator==(const Counter& lhs, const Counter& rhs);
};

// ОПРЕДЕЛЕНИЕ функции-друга (обычная глобальная функция)
bool operator==(const Counter& lhs, const Counter& rhs) {
    return lhs.value == rhs.value; // ✅ Можно! Прямой доступ к private полю
}
```

#### Конструктор копии
Новый экземпляр обьект получит свое состояние не с 0, а путем копирования данных из уже другого обьекта. Он выглядит вот так:
```c
 MyClass(int value) : data(value) {}
    // Конструктор копии
    MyClass(const MyClass& other) : data(other.data) {
        // тело (может быть пустым)
    }
```
Конструктор класса может быть быть вызван в 3 основных ситуациях:
1.  Просто копирование обьекта - 
```c
MyClass b = a;     // вызов конструктора копии
MyClass c(a);      // тоже вызов конструктора копии
```
2.  Передача в функцию по значению
   ```c
   void func(MyClass obj);
   ```

Зачем же он нужен? Он решает проблему *поверхностного копирования*.  Рассмотрим пример. Допустим в классе определено свойство *int\* value*.  При поверхностном копировании компилятор тупо скопирует указатель и объекты будут указывать на 1 и ту же память.  Поэтому нужно писать конструктор копии самому - *deep copy*.
#### Lambda-функции
```c
[] (параметры) { действия }
```
Код ниже определит и сразу вызовет нужную функцию
```c
[](){std::cout << "Hello" << std::endl;} ();
```
Именованные лямбда-выражения:
```c
auto hello { [](){std::cout <<` `"Hello"` `<< std::endl;} };
hello();
```
Если внутри лямбда-функции нужно использовать какие-то переменные их надо добавить в скобки. Пример:
```c
for (int i =0  ; i < a ; ++i) {
        [&i](){ // если написать просто &, то поймаются все переменные
            std::cout << i << std::endl;
        } ();
    }
```
Лямбда с возвращением значения с явным указанием типа:
```c
auto sum { [](int a, int b) ->` `double` `{return a + b;} };
```

#### Перегрузка операторов
1 пример:
Здесь оператор + переопределен для объектов класса Counter.  Возвращаемое значение - int, сложение 2 значений полей value. 
```c
class Counter {
    int value;
    public:
        int operator+ (const Counter counter) {
            return this->value + counter.value;
        }
        Counter(int value) {
            this->value = value;
        }
};
int main() {
    int val1, val2;
    std::cin >> val1 >> val2;
    Counter cl1 = Counter(val1);
    Counter cl2 = Counter(val2);
    int ans = cl1 + cl2;
    std::cout << ans;
}
```
Это для функций, которые являются членом класса. Для функций которые не являются членом класса, будет нечто вот такое:
```c
`ReturnType operator Op(``const` `ClassType& left_operand, Type right_operand);`
```
То есть помимо правого операнда добавляется левый.
В примере ниже будет возвращаться уже обьект а не значение.
```c
class Counter {
    int value;
    public:
        int get_value() {return this->value;}
        Counter* operator+ (const Counter counter) {
            return new Counter{this->value + counter.value};
        }
        Counter(int value) {
            this->value = value;
        }
};
int main() {
    int val1, val2;
    std::cin >> val1 >> val2;
    Counter cl1 = Counter(val1);
    Counter cl2 = Counter(val2);
    Counter* ans = cl1 + cl2;
    std::cout << ans->get_value();
}
```
Данная конструкция фактически является просто конструктором, за исключением того, что она работает для любый типов
```c
Counter{this->value + counter.value}
std::vector<int>a{1,2,3,4};
```
Для операторов сравнения:
```c
bool operator==(const Counter& lhs, const Counter& rhs) {
    return lhs.get_value() == rhs.get_value();
}
```
Для простых сравнений можно использовать *default*. По умолчанию будут сверяться все поля класса, для которых определены операции сравнения
```c
`bool` `operator == (``const` `Counter& counter)` `const` `=` `default``;`
```


#### Семантика перемещения***
Мы удаляем обьекты и передаем их данные другим обьектам. Иногда мы не хотим копировать обьект  Строго говоря мы перехватываем не указатели, а владение. У сырых указателей нет такого понятия как владение. Зато оно есть у умных указателей - *std::unique_ptr*, например.
В C++ есть несколько специальных типов данных.
1. *lvalue* - классическое значение; *int a = 10* -  *a* имеет тип l-value
2. *rvalue*.  во-первых есть x-value и *p-value*. С *p-value* все понятно, это чистое правое значение, то есть, например просто число *3*. С *x-value* - ресурсы такого обьекта можно передать в перемещающий конструктор обьекта.

Меняя категорию на *rvalue* компилятор понимает, что  эти данные можно использовать. Для лучшего понимания, рассмотрим пример из Boost.Asio
```c
std::make_shared<session>(std::move(*socket))->start();
```
Что именно делает этот код.
1.  *\*socket* становится типом *rvalue*.  Это работает только для типов, у которых есть *перемещающий конструктор* 
```c
std::move(*socket)
```
2. _«std::make_shared создаёт объект session, передавая в его конструктор rvalue-ссылку на сокет. Конструктор session перемещает сокет во внутрь объекта, после чего исходный сокет становится пустым (moved-from). Полученный shared_ptr затем используется для вызова start().»_
```c
std::make_shared<session>(std::move(*socket))
```

Передаем rvalue в параметр конструктора. Однако в C++ если у параметра есть имя, то внутри функции он l-value, независимо от того, как он обьявлен. Поэтому используем std::move еще раз
```c
public:
	session(boost::asio::ip::tcp::socket&& socket) :
		socket(std::move(socket)) {}
```

У обычного указателя нет  конструкторов. Но он есть у умных указателей. Например:
```c
std::unique_ptr<std::string> ptr1 = std::make_unique<std::string>("hello");
std::unique_ptr<std::string> value = std::move(ptr1);
```
Это сработает
