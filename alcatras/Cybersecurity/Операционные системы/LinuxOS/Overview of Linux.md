Здесь про то как Linux представлена для обычного программиста.  
В общем в Linux изначально заложен смысл, что много программистов, которые разбираются в своем деле, работают вместе.
Система должна быть простой, но при этом гибкой в использовании. То есть должно быть много простых элементов, которые можно комбинировать бесконечным числом способов. Еще не нужна избыточность, пример: *cp f1 folder1*

Из того, что интересного в этой главе:
*pr* - готовит файл для печати
*make* - вообщем часто же используются файлы заголовков. Если заголовок меняется, все программы где он включен нужно рекомпилировать. Make позволяет им рекомпилироваться автоматически.  Вообще у меня есть заметка по linux, где все намного подробнее.
