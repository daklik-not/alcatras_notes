**PID** - ID процесса.
**TTY** - **controlling terminal**,  связанный с процессом. 
Терминал, который выполняет команду. Есть 2 типа terminal devices.  Обычный terminal device  -  нативный терминал, в который можно что-то писать.  Например терминал tty1. Он напрямую управляется ядром LInux. Есть псевдотерминал. Это с чем непосредственно работает пользователь. Если ввести команду tty, то будет что то вроде dev/pts/1. Это и есть псевдотерминал.

**STAT** -  код статуса процесса
**TIME** - полное время использования процесса

**Сигналы**
Сигнал - увежомление процессу, о том что что то произошло. Например специальные команды юзера - CTRL+C, аппратные и программные прерывания, межпроцессорное взаимодействие.
Прерывания -  [Устройство Компьютера] - без ссылки потому что на графе некрасиво
**Signal  mask** -  битовая карта, в которой каждый бит соответствует какому-то сигналу.  Она нужна для блокировки сигналов.
**Process niceness** -  величина которая оказывает насколько процессор хочет завладеть ресурсами процессор для мультипрограммирования. Если низкое или отрицательное, то высокий приоритет. Если нет то низкий.

| SIGHUP или HUP    | РАзрыв соединения, например при выходе из SSH  сессии.          |
| ----------------- | --------------------------------------------------------------- |
| SIGINT или INT    | Прерывание                                                      |
| SIGKILL или KILL  | убить процесс. не блокируется сигнальной маской                 |
| SIGSEGV или SEGV  | ошибка сегментации (попытка доступа к запрещенно памяти)        |
| SIGSTERM или TERM | Завершение программного обеспечения. ЗАпрос завершения процесса |
| SIGSTOP или STOP  | принудительная остановка. Обратная операция - SIGCONT           |

**Pthreads Signals**
Это немного не в тему тут, но пусть будет
```c
// В потоке-получателе:
sigset_t mask;                     // 1. Объявляем маску
sigemptyset(&mask);                // 2. Очищаем
sigaddset(&mask, SIGUSR1);         // 3. Добавляем SIGUSR1
pthread_sigmask(SIG_UNBLOCK, &mask, NULL);  // 4. Разблокируем

int sig;
sigwait(&mask, &sig);              // 5. Ждем здесь
// Поток просыпается тут!

// В потоке-отправителе:
pthread_kill(target_thread, SIGUSR1);  // 6. Отправляем сигнал
```
