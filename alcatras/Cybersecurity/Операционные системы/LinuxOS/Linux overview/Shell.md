#### Shell
**Shell** - это интерфейс для работы системы в виде командной строки
Сначала был Bourne shell, сейчас **bash**
Shell - обычная пользовательская программа.
Пример: cp src dest - команда копирования
Есть **флаги**, перед которыми пишется **-**
Чтобы было проще работать с файлами придумали **wild cards**. Короче регулярки обычные)
*ls \*.c* - пример
У любой **CLI-(command-line-interface)** программы есть специальные файлы, из которых она получает ввод и вывод от терминала, который в свою очередь работает с ОС.  Это потоки *stdin, stdout, stderr*.

Чуть чуть про терминалы. Не у каждой программы есть терминал. На практике только CLI программы работают через терминал. Вообще, терминал это интерфейс для шелла на ОС. То есть шелл записывает в файл, а то что там написано до ОС уже доносит терминал. Терминал такая же пользовательская программа.
____

Есть **pipes(пайпы)**. Оно говорит использовать вывод одной программы как ввод другой.

Амперсандом (&) можно отправить работу на задний план - много процессов.
