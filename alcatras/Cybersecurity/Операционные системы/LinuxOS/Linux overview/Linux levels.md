Поверх *hardware* работает сама ОС. ОС дает интерфейс системных вызовов для более высоких уровней. 
Программы делают системные вызовы, помещая аргументы на регистры или стек, вызывая trap инструкцию. Поскольку на C невозможно указать точную память, куда надо поместить аргументы, то библиотека обеспечивается одной assembler процедурой на системный вызов - они помещают аргументы в специальное место и вызывают trap инструкцию. Стандарт закреплен POSIXом. 
Собственно сам пользователь чаще всего работает с  специальными стандартными программами, вроде того же шелла. 
Популярные GUI: GNOME, KDE. За накладывание окон, взаимодействие пользователя с ними занимается. За это отвечает специальная  система X. Она состоит из X-server - главный компонент, он контролирует устройства такие как мышка клавиатура экран и отвечает за перенаправления ввода и вывода между этими устройствами. 
GNOME → Xlib → X Server → ядро (через драйвер для смены курсора) - примерно так.
