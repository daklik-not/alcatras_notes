#### Disk Quotas
На мультипользовательских ОС нужен механизм ограничивающий объём диска, используемый пользователем. Ниже обычный механизм
Когда пользователь открывает файл, метаданные и адреса блоков на диске обнаруживаются и помещаются в таблицу в главной памяти. В метаданных есть информация о владельце.
Вторая таблица содержит запись квоты для каждого пользователя - эта таблица лежит в специальном разделяемой файле квоты. В RAM находятся не вся таблица, а отдельные записи для каждого пользователя. Когда все файлы пользователя закрыты запись записывается на диск.
![[Cache/Pasted image 20260128195446.png]]
При расширении файла, каждый раз при добавлении блока мы будем проверять сначала **soft limit** - который можно превзойти и **hard limit** который нельзя. Если лимит превышается - error. Такие же лимиты для количества файлов, чтобы не занимать количество i-node.
При превышении soft лимита, выдается предупреждение. Если предупреждений слишком много, пользователю не разрешаются логинится.
