#### File Access + File attributes/metadata
Ранние ОС поддерживали только один тип доступа к файлам - последовательный доступ.  В таких системах, процесс должен был читать все байты по порядку, начиная с начала, но не мог пропускать их, или читать не по порядку. Можно было отмотать назад файл
С появлением дисков, появилась возможность читать байты или записи из файла не по порядку или получать записи по ключу а не по позиции. Файлы чьи байты или записи можно читать не по порядку называются **Random acsess files**. Random access файлы полезны для баз данных -> если пользователь хочет зарезервировать место в ресторане, то каждому пользователю не надо каждый раз читать все байты файла с начала - он просто запишет в нужное место.
В современных системах устанавливается параметр **seek** - он показывает с какого места надо читать файл. Seek - Указатель позиции в файле.
____

У каждого файла помимо имени и данных есть **метаданные**. Их набор определяется системой.  На картинкые таблица с основными метаданными. Первая подгруппа отвечает за принадлежность/защиту. Вторая это просто флаги, которые могут выполнять любые функции. Третья для файлов, использующих ключи.
