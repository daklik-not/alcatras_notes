File operations
Есть набор стандартных системных вызовов для работы с файлам

| Операция       | Описание                                                                                                                                                                                                                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Create         | Создает файл без данных,  устанавливает некоторые атрибуты                                                                                                                                                                                                                                                                                        |
| Delete         | Файл удаляется, очищая место на диске                                                                                                                                                                                                                                                                                                             |
| Open           | Сначала надо открыть. Смысл этого вызова в том, чтобы ОС могла загрузить все метаданные и набор дисковых адресов в RAM. Сами данные чаще всего загружается on-demand - с каждым page fault                                                                                                                                                        |
| Close          | Когда атрибуты и адреса диска больше не нужны, файл должен быть закрыт, чтобы освободить место в системных таблицах. Многие системы устанавливают лимит на количество открытых файлов для процесса. ОС накапливает в своих структурах память размером целого блока диска, чтобы записать все сразу. close() заставит записать незаконченный блок. |
| Read           | Чтение данных с файла с позиции seek. Нужно указать количество данных и буфер                                                                                                                                                                                                                                                                     |
| Write          | Запись с текущей позиции. Если текущая позиция в конце - размер файла увеличивается, если в середине, данные перезаписываются                                                                                                                                                                                                                     |
| Append         | То же самое что и write но только в конец                                                                                                                                                                                                                                                                                                         |
| Seek           | Определяет позицию для чтения/записи в файле.                                                                                                                                                                                                                                                                                                     |
| Get attributes | Читает метаданные файла. Например для UNIX make программ - она использует метаданные для корректного совмещения<br>**ПОЧИТАТЬ ПРО MAKE!!!**                                                                                                                                                                                                       |
| Set attributes | Некоторые атрибуты могут меняться по мере существования файла. Меняет метаданные файла                                                                                                                                                                                                                                                            |
| Rename         | Переименование файла                                                                                                                                                                                                                                                                                                                              |
#### Example of Program
Это классический паттерн работы с файлами на низком уровне
```c
//стандартные библиотеки для международного стандарта
#include <sys/types.h> 
#include <fcntl.h>
#include <stdlib.h>
#include <unistd.h>
//хорошая практика так обьявлять константы в системной разработке
#define BUF_SIZE 4096
#define OUTPUT_MODE 0700
int main(int argc, char *argv[]) 
{
	//args - количество строк на ввод, argv сами строки
    int in_fd, out_fd, rd_count, wt_count;
    char buffer[BUF_SIZE];
    if (argc != 3) exit(1); 
    /* Open the input file and create the output file */
    in_fd = open(argv[1], O_RDONLY);  //работаем с файлами через дескрипторы
    if (in_fd < 0) exit(2); 
    out_fd = creat(argv[2], OUTPUT_MODE);
    if (out_fd < 0) exit(3); 
    /* Copy loop */
    while (1) {
	    //вот здесь паттерн записис
	    //мы копируем не весь файл сразу, а сначала записиываем часть в буфер, потом копируем на другой файл.
        rd_count = read(in_fd, buffer, BUF_SIZE);
        if (rd_count <= 0) break;
        wt_count = write(out_fd, buffer, rd_count);
        if (wt_count <= 0) exit(4); 
    }
    /* Close the files */
    close(in_fd); // закрываем файлы, читай освобождаем место в системных таблицах
    close(out_fd);
    if (rd_count == 0)
        exit(0);
    else
        exit(5);
}
```
