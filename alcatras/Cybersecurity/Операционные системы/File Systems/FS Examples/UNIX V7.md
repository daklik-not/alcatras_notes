### UNIX V7
#inode  - там немного про иноды
Здесь описана не современная UNIX FS.
**Cтруктура + атрибуты**
Структура ФС UNIX выглядит как DAG - с учетом ссылок, с корневой директорий.
UNIX использует подход с классическим инодами, где вхождение в директорию содержит только номер инода и имя - максимальная длина - 14символов. Атрибуты самого инода - размер файла, создание, последний доступ, владелец, группа, защитная информация, счетчик ссылок - короче почти как на modern linux.
Чтобы искать адреса файлов используется лестничная структура:
**Хранение адресов**
В иноде хранится небольшое количество адресов -> в **single indirect блоке/блок одинарной косвенной адресации** хранятся еще адреса -> в **double indirect блоке** хранятся адреса, указывающие на список single indirect блоков -> если этого недостаточно то используется **triple indirect блок**: сначала на double, потом на single.

**Полный путь открытия файла - /usr/ast/mbox**
1. В UNIX инод корневой папки расположен в фиксированном месте - обращаемся к нему
2. Далее ищем первый компонент пути в корневой папке. 
3. Находим и повторяем пока не дойдем до папки в которой лежит файл
4. Читаем инод файла, записываем в RAM и храним там до закрытия файла
