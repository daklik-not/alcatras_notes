### MS-DOS 
MS-DOS - операционная система, не файловая

MS-DOS используют различные электронные устройства с embedded системами - например цифровые камеры,
Чтобы прочитать файл MS-DOS должна сначала выполнить *open(path)* системный вызов. Сначала ФС доходит до финальной директории файла.
Каждый свободный блок помечался специальным кодом. Когда MS-DOS нужен новый блок диска, он ищет в FAT вхождение содержащее этот код.

**FAT FS**
![[Pasted image 20260131190625.png]]
Название зависит от того, сколько битов содержит адрес диска. На FAT32 только 28 битов использовались для адреса. Еще есть exFAT - единственная система, с помощью которой можно передавать файлы между MacOS и Windows.
Размер блока диска - кратен 512 байтам. Для каждого раздела устанавливался свой размер блока диска, который брался из набор размеров блоков - **cluster sizes**. 

**FAT12** - максимальный размер раздела 4096 \* cluster size.  В вхождении в таблицу FAT хранилось номер следующего блока, то есть 12 бит, которые находились в 2 байтах. При увеличении размеров блоков, очевидно, можно было увеличить размер раздела, что microsoft и сделали позднее.

**FAT16** - 16битные номера блоков  Наибольший размер раздела - 2GB, наибольший диск - 8GB, то есть 4 раздела. Добавлены 8,16,32 КБ страницы.

**FAT32** - 28битные номера блоков. Максимальный размер раздела 2TB, потому что на физическом уровне диск разбивал себя на сектора размером 512байт, и чьи номера адресовались 32битными числами. Так же можнол
