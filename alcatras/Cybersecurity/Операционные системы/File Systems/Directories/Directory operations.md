#### Directory Operations

| Команда   | Описание                                                                                                                                                                                                                                                            |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Create    | создание директории, Linux: mkdir<br>при создании в директории только ```.. и .```                                                                                                                                                                                  |
| Delete    | удаление, Linux: ``rmdir`` - для удаления пустой<br>``rm -rf`` - для удаления не пустой<br>                                                                                                                                                                         |
| Open Dir  | Иногда нужно открыть файлы директории для чтения - например, чтобы вывести список всех файлов                                                                                                                                                                       |
| Close Dir | После чтения надо закрыть, чтобы очистить структуры таблиц ядра - например записи, связанные с этим в PCB                                                                                                                                                           |
| ReadDir   | Чтение файла директории. Ниже программа.                                                                                                                                                                                                                            |
| Rename    | Переименование директории                                                                                                                                                                                                                                           |
| Link      | Этот системный вызов определяет существующий файл и путь, после чего создает ссылку с существующего файла на имя, определяемое путем. Таким образом один файл появляется в нескольких директориях - **hard link**                                                   |
| Unlink    | Вхождение файла в директорию убирается. Если количество ссылок файла равно 0, то он удаляется из файловой системы. Если нет, то удаляется ссылка. Казалось бы нет отличий от delete. А в целом так оно и есть - в UNIX системный вызов для удаления файлов - unlink |
Пример программы для чтения файла директории на UNIX-like системах, хотя поля могут отличаться. Структура Dirent используется для представления записей в директориях.

```c
#include <sys/types.h>
#include <fcntl.h>
#include <stdlib.h>
#include <iostream>
#include <unistd.h>
#include <sys/types.h>
#include <dirent.h>

struct dirent1 {
  ino_t          d_ino;       /* inode number */
  off_t          d_off;       /* offset to the next dirent */
  unsigned short d_reclen;    /* length of this record */
  unsigned char  d_type;      /* type of file; not supported
                                 by all file system types */
  char           d_name[256]; /* filename */
};

int main()
{
    DIR *dir;
    struct dirent *entry;
    dir = opendir("/");
    if (!dir) {
        std::cerr << "error in creating process";
        exit(1);
    }
    while ((entry = readdir(dir)) != NULL) {
        std::cout << entry->d_ino << " " << entry->d_name << " " ;
        std::cout << entry->d_type << " " << entry->d_reclen << std::endl;
    }
    closedir(dir);
    return 0;
}

```
Кроме **hard** линков есть еще симлинки - **symbolic links**. Их отличие в том, что они ссылаются не одну структуру ядра, как hard линки, а на главную ссылку типо. Я думаю потом это будет объясняться, но главная идея в том, что если отцепить hard линк у первого файла, то просто удалится одна ссылка, а если у симлинка, то отвалятся все симлинки.
