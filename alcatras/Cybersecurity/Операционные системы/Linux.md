#### История UNIX

Ну в общем там много воды в книге. Из сути выделю то, что после CTSS и MULTICS Кен Томпсон разработал для себя систему, которая была урезанным MULTICS, которую позднее назвали UNICS, которую позднее поменяли на **UNIX**
Потом UNIX переписали с ассемблера на B. Томпсон был в департаменте Денниса Ричи. После того как Ричи придумал C, они вместе переписали UNIX на C. 
 UNIX был открытый код для универов. Из-за того что исследователи могли в нем копаться, обмениваться на конференциях, UNIX быстро совершенствовался. Microsoft даже покупала UNIX для себя, но позднее в Windows это не использовалось. Чтобы UNIX можно было переносить между машинами, сначала чел из департамента Ричи разработал **portable C compiler**  - один и тот же код можно было скомпилировать под разные машины.
 Позднее компания, которая владела UNIX релизнула **System 5** - уже коммерческий проект.
 Университет Беркли разработал **4BSD**, улучшенную Version 7 UNIX. Например туда завезли виртуальную память. В этой системе был представлен стек протоколов **TCP/IP**
 Мир разделился на System 5 и 4.3BSD. Позднее IEEE разработало **POSIX**  стандарт.
 Таненбаум написал MINIX, который был нужен для образовательных целей и не уступал. MINIX была основана на микроядерном устройстве.
#### История Linux
Первая версия Linux релизнута в 1991 году Линусом Торвальдсом. Это была монолитная система, где большинство кода было в ядре. У Linux была проблема, что gcc это огромный монолитный код, выполнение которого довольно долгое. Короче его компоненты нельзя использовать по отдельности. Есть какой-то LLVM, который позволяет эти модули по отдельности использовать и он типо лучше.
 Следующая версия включала в себя поддержку TCP/IP, MMAP, новую FS. Linux разрабатывалась большим количеством людей, и редактировалась Торвальдсом.
 Много кода с UNIX было перенесено на LINUX. GUI: GNOME, KDE.
 Linux бесплатный, код можно распространять. При этом нельзя продавать или распространять только в бинарной форме работы, которые наследуют ядро Linux - всегда должен быть открытый код.
