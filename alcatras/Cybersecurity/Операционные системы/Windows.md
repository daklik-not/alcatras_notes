#### Небольшая историческая справка
Сначала Microsoft купила копию популярной в то врем операционной системы CP/M, и назвала ее **MS/DOS** и лицензировала ее для IBM. Далее Microsoft решила создать графический интерфейс для MS-DOS и назвала его **Windows**.  В 90 появилась Windows 3. В то время процессы были в 1 адресном пространстве. Далее поверх MS-DOS создали Windows 98 и Windows ME.
Через какое-то время MS/DOS была признана устаревшей и небезопасной. Была разработана **NT** система - *NT OS/2*.  Она работала на разных процессорах, разделение на режим пользователя и ядра, вытесняющая многозадачность. Первая версия Windows на NT называлась *Windows NT 3.1*. Также она поддерживала MS-DOS based Windows - если вкратце, то ОС видело старый вызов, и выполняла вместо него новый. API назывался **Win32**.  На картинке видно, что программа на Win32 выполняется практически на всех версиях Windows.
![[Pasted image 20260710122923.png]]
Далее Windows NT 4.0.  После Windows 2000 - самое важное ее улучшение в том, что внедрилось *pug-and-play*. Раньше, при подключении устройства,  нужно было вручную настраивать джамперы(такие штуки на материнской плате) чтобы дать устройствам правильный IRQ и адреса памяти. На Windows 2000 это стало работать автоматически. Далее вышла *Windows XP*.  В основном это были улучшения пользовательского интерфейса. В 2006 вышла Windows Vista - за ней в 2008 Windows Vista Server. Vista показала себя плохо с точки зрения производительности. Эти проблемы были разрешены в *Windows 7* - которая стала самой популярной ОС на долгие годы
Чтобы конкурировать на рынке мобильных вычислений(телефоны, планшеты) Microsoft была нужна ОС, которая будет работать на многих типов устройств. Они выпустили Windows 8. Ее особенность в том, что использовалась **OneCore** архитектура. Ее смысл в том, что есть маленькое ядро, которое одинаково для всех типов устройств, но при этом оно расширяется в пользовательском пространстве для каждого конкретного типа устройства. Тем не менее из-за проблем с пользовательским интерфейсом и другими Windows 8 даже близко не достигла такого же коммерческого успеха как Windows 7 или другие версии
Далее вышла Windows 10.  Она дала разработчикам единую платформу для всех устройств - **UWP**.  1 и тот же код работал на всех устройствах с Windows. Тем не мене разработчики встретили UWP негативно - сейчас никто на ней уже не пишет. Самая коммерчески успешная версия Windows.
Далее вышла Windows 11. Новый пользовательский интерфейс. Однако она содержала много изменений под капотом. Улучшение производительности, питания, 64 процессора на сокет материнской платы. Добавление эмуляции 64 битных приложений на arm ноутбуках. Но самое важное - безопасность. Secure Boot, Device Guard, Applica tion Guard, and kernel-mode Control Flow Guard - все это можно использовать. Также добавляется ***Harware Stack Protection***
