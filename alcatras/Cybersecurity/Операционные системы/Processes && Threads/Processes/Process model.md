**Process model**
Запущенное ПО на устройстве разбивается на процессы.
У каждого процесса есть свой собственный логический **program counter(адрес следующей инструкции процессора)** Этот логический program counter сохраняется в физический единственный program counter процессора.
![[Cache/Pasted image 20251027221216.png]]
В этой главе рассматриваются только однопроцессорные системы. Процессы не должны быть запрограммированы, опираясь на их время выполнения, поскольку неизвестно сколько context switch произойдет. 
Программа - просто текстовый файл, который говорит процессу, что делать
Процесс - сама программа, которая уже что-то делает.
Запущенное приложение не состоит из одного процесса. Оно может состоят сразу из большого количества.
