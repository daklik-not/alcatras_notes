**Process states**
Существует 3 состояния в которых может находиться процесс.
1. Активное состояние. Процесс выполняет работу
2. Готовое состоние. Процесс готов выполнить работу, но не может из-за мультипрограммирования, то есть в текущий момент времени какой-то другой процесс занимает процессорное время
3. Заблокирован. Процесс не хватает каких-то данных для продолжения. Например, один процесс не может продолжить работу, пока другой не закончит чтение данных с диска.

Распоряжением процессорного времени между процессами занимается **scheduler**. Он являет собой часть операционной системы. Все детали запуска скрыты в нем, в то время как остальная часть операционной системы спрятана за красиовй моделью процесса.
