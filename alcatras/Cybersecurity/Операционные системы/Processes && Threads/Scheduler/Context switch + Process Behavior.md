#### Context switch
1. Переход из user мода в kernel мод.
2. Сохранение состояния текущего процесса, включая сохранение его регистров в process table, чтобы они могли быть загружены позднее.
3.  На некоторых системах также нужно сохранять memory map - это такая таблица, которая хранит информацию о том, какие страницы находятся в памяти или свободны, какие находятся в кэше, какие используются процессами. Сохраняем вместе с reference битами - биты, которые показывают обращался ли процесс недавно к этой странице памяти.
4.  Новый процесс должен быть выбран путем алгоритма планирования.
5. MMU - (напомню, это такая штука, которая преобразовывает виртуальную память в реальную) должен загрузить карту памяти нового процесса.
6. Новый процесс запускается.
 Вдобавок к этому надо проверять страницы на наличие их в кэше - по-умному - инвалидация TLB и кэш-линий (TLBто _специальный кэш внутри процессора_, который ускоряет преобразование **виртуальных адресов** (которые использует программа) в **физические адреса** (которые нужны CPU для доступа к реальной памяти. Если говорить попроще, то виртуальный адрес определенным способом преобразуется и получаются индексы таблицы, с помощью которой процессор быстро получает доступ к памяти внутри самого себя).
 Короче говоря это очень дорогая операция
***Важно!!!***  При  смене контекста процессы не блокируются, а приостанавливаются, если процесс не блокируется сам.
#### Process behavior
**CPU-bound processes** - процессы, которые большую часть своего времени тратят на вычисления
**I/Obound processes** - процессы, которые тратят большую часть своего времени ожидая IO.
На картинке показано, как сильно отличаются **CPU burst(читай время выполнения процессором до I/O)** различных процессов.

По мере того, как процессы становятся быстрее, процессы становятся более IO bound. Как следствие планирование IO bound процессов может стать более важным в будущем. С другой стороны процессоры тоже не будут становится быстрей, потому что они производят слишком много тепла. 
Алгоритм планирования очень сильно зависит от контекста.
