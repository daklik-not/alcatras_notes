### Virtual memory
Есть проблема, связанная с тем, что некоторые программы слишком большие, чтобы постоянно полностью находится в оперативной памяти. Придумали решение, которое называется виртуальная память - **virtual memory**. Каждая программа имеет свое собственное адресное пространство, которое разбито на части, которые называются страницы - **pages**.  Каждая страница это смежный набор адресов. Каждая страница отображалась в физическую память. При этом программа может работать, даже если не все страницы находятся в ОЗУ в текущий момент.
Когда необходимая страница находится в ОЗУ, то MMU просто на лету переводит виртуальный адрес в физический. Если нет, то ОС подгружает страницы с диска, и повторно выполняет инструкцию. Большинство систем использую страницы, каждая из которых ссылается на фиксированное количество памяти. Оно хорошо работает в условияХ мультипрограммирования - пока программа ждем, пока данные подгрузятся, может быть запущена другая программа
