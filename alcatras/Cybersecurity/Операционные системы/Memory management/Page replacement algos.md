### Page replacement algorithm

Когда происходит page fault, операционная система должна освободить место в памяти для новой страницы. Чтобы сделать это, она выбирает страницу для выгрузки. Если страница была изменена (modified bit = 1), то ее необходимо записать на диск; если не была изменена — просто выгрузить.

Одним из ключевых вопросов при замене страниц является выбор страницы для выгрузки. Логично выбрать ту страницу, которая использовалась наименее часто, но этот подход не всегда оптимален.
#### Optimal page replacement algorithm

Основная идея оптимального алгоритма замены страниц заключается в том, чтобы предсказать, когда страница снова понадобится. Теоретически, если мы знаем, что страница будет использоваться позже (например, через несколько инструкций), то нет смысла выгружать её в данный момент.

Однако на практике этот алгоритм невозможно реализовать: операционная система не может предсказать, сколько инструкций осталось до следующего обращения к странице. В идеале можно было бы попытаться использовать информацию о планировании процессов, но в реальности операция выгрузки страницы должна быть намного быстрее, чем обращение к планировщику процессов.
