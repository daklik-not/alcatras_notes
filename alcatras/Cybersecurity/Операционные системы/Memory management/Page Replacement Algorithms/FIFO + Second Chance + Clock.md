#### FIFO - First-In, First OUT page replacement algorithm

Операционная система реализует linked list всех страниц в памяти, где head - самая недавняя страница, tail - самая раняя. При page fault очевидно новая страница добавляется в хвост, а старая убирается из головы. Однако этот алгоритм не используется в чистой форме - старая страница все еще может быть полезной.

#### Second Chance Page Replacement Algorithm

Модификация для FIFO. Прежде чем заменить страницу в начале связного списка, ОС проверяет reference bit этой страницы. Если он равен 0 - страница старая и не используется, то она немедленно заменяется. Если он равен 1 - страница снова отправляется в конец. Эта операция называется **second chance**. Chat GPT пишет, что для реализации second chance обычно используется круговая очередь. Потом как-нибудь почитаю про нее.
Если все страницы равны 1, то спустя какое-то время - clock interrupt, самая старая из них занулит свой бит и произойдет смена - ведь таблица страниц принадлежит только одному процессу. Проблема такого подхода, что нужно постоянно двигать страницы по списку.

#### Clock page Replacement algorithm

Почти то же самое. Но здесь, когда страница попадает в память, мы не помещаем ее в конец. Короче говоря просто в той же ячейке массива в которой находимся записываем, новую страницу. Потом двигаем **hand**, это стрелочка на рисунке. Через какое то время hand просто вернется в начало. Утверждается, что это лучше чем linked list, потому что во-первых не нужно хранить n указателей, во-вторых впринципе манипуляций с памятью меньше.
