#### The not recently used page replacement algorithm - NRU

Операционная система использует reference и modified биты, для того, чтобы лучше выбирать страницу для выгрузки. Обычно hardware имеет эти биты - то есть оно автоматически меняет их при ссылке и редактировании. Однако если его нет, используются механизмы ОС. Когда процесс запускается, все его вхождения в таблицу страниц помечены, как не находящиеся в памяти. Как только на какую-то страницу ссылаются, происходит page fault.  Далее ОС устанавливает в своих внутренних таблицах R bit, и меняет вхождение таблицы страниц на правильный страничный кадр с режимом Read Only и перезапускает инструкцию. Если происходит еще один page fault, тогда ОС меняет уже на режим Read/Write.

Когда процесс запускается, все биты установлены в 0. Раз в какое-то время - clock interrupt, биты очищаются. Различают 4 класса страниц
	Class 0: not referenced, not modified. 
	Class 1: not referenced, modified.  - кажется, что это невозможно, однако такое может быть если reference бит очищается. В отличие от reference бита, modified бит нельзя очищать, иначе  просто потеряются изменения.
	Class 2: referenced, not modified. 
	Class 3: referenced, modified.
**NRU**  алгоритм заключается в том, что просто убирать рандомные страницы с самым низким классом. Этот алгоритм выдает вполне приемлемый результат
