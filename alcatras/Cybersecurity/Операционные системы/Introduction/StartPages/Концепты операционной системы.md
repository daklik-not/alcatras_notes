**Protection**.  
Файлы в UNIX защищены 9-битной маской прав доступа. Этот код состоит из 3 групп по 3 бита: для владельца (user), для группы владельца (group), и для всех остальных (others). Каждая группа битов отвечает за три типа доступа: чтение (r), запись (w), выполнение (x). Такие права называют _**rwx bits**_. Выглядят примерно так: `rwxr-x--x`. Дефисы означают, что соответствующий доступ запрещён. Если права применяются к _директории_, то бит выполнения (x) отвечает за возможность входа в эту директорию и поиск в ней (доступ к содержимому). Основная часть про безопасность будет в главе 9.
