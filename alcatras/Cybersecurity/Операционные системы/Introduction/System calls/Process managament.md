**fork** - основной способ создать процесс в POSIX. Создает дубликат оригинального процесса, включая все файловые дескрипторы, регистры и состояние памяти. После fork каждый процесс выполняется независимо. Память разделяется по принципу **copy-on-write**: процессы используют общую физическую память до первого изменения, после чего ОС создает копию только модифицируемой страницы. Это экономит память и ресурсы. Вызов fork возвращает 0 в дочернем процессе и **PID (Process IDentifier)** в родительском
PS: в UNIX-like системах у каждого процесса есть PPID(id  родителя). При запуске системы создается процесс **init**. От него через fork создаются все остальные процессы.

Рассмотрим пример с shell. Пользователь вводит команду, shell создает дочерний процесс через fork, затем родительский процесс вызывает **waitpid** для ожидания завершения дочернего. Параметр **pid** указывает, какой процесс ожидать (-1 для любого дочернего). В **status** сохраняется статус завершения. Параметр **options** может включать флаг **WNOHANG**: если дочерний процесс еще выполняется, waitpid немедленно возвращает 0, не блокируя родителя; если завершился - возвращает PID.
PS:  Если родительский процесс завершается раньше дочернего, то вызов waitpid выполняет начальный вызов init. Если ребенок завершается раньше того как родитель вызовет waipid, то процесс превращается в зомби процесс,  чьи ресурсы свободны для использования другими процессами. Тем не менее его запись в process table сохраняется, и если таких процессов будет слишком много, то другие процессы просто не будут создаваться.

Дочерний процесс вызывает **execve** с параметрами: путь к исполняемому файлу, массив аргументов (**argv**), массив переменных окружения (**envp**).
**envp** содержит строки вида "КЛЮЧ=значение" с информацией о среде (например, USER=имя_пользователя).


```
#define TRUE 1
while (TRUE) {
	type prompt( );
	read command(command, parameters);
    if (fork( ) != 0) {
	    waitpid( 1, &status, 0);
	} else {
		execve(command, parameters, 0); 
	} 
}
```

Пример для `cp file1 file2`:  
После fork дочерний процесс вызывает `execve("/bin/cp", ["cp", "file1", "file2"], environ)`. Программа `cp` в своей функции `main` получает аргументы:       
```
int main(int argc, char *argv[], char *envp[]) {
    // argc = 3
    // argv[0] = "cp", argv[1] = "file1", argv[2] = "file2"
}
```
.
system call **exit(status)** завершает процесс, возвращая статус (0-255) в **waitpid**..
Процессы в UNIX содержат сегменты: **text** (код), **data** (инициализированные данные), **stack** (стек). Между data и stack находится область для динамического выделения памяти (**heap**), которая расширяется вызовом **brk/sbrk**. Для работы с памятью используют библиотеку **malloc**, так как brk не стандартизирован POSIX.
