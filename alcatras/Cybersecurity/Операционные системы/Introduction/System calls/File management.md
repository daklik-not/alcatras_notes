Системные вызовы для работы с файлами:  
**open** определяет флаги: O_RDONLY (чтение), O_WRONLY (запись), O_RDWR (чтение и запись). Для создания файла используется O_CREAT. Возвращаемый файловый дескриптор используется для операций чтения/записи. После работы файл закрывается через **close(fd)**, освобождая дескриптор для повторного использования.

Большинство программ работают с файлами последовательно. Текущая позиция (указатель) определяет место следующей операции чтения/записи. **lseek(fd, offset, whence)** изменяет позицию:

- `fd` - файловый дескриптор
    
- `offset` - смещение в байтах
    
- `whence` - точка отсчета (SEEK_SET - начало файла, SEEK_CUR - текущая позиция, SEEK_END - конец файла)
    

UNIX хранит метаданные файла (размер, время изменения, права доступа, inode) в структуре **stat**. **stat(path, &buf)** получает данные по имени файла, **fstat(fd, &buf)** - по открытому дескриптору. Результат сохраняется в `buf` (структура stat).
