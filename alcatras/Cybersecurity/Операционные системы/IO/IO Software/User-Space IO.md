Есть небольшое количество библиотек процедур, которые находятся в пользовательском пространстве - используя их пользовательские программы через системные вызовы могут получить доступ к IO. Большинство таких процедур являются просто обертками для системных вызовов. Есть и не такие - *printf, scanf*.
*Spooling*
Это метод управления доступа процесса к IO. Создадим spooling директорию и процесс демон. Процесс создает целый файл и помещает его в директорию. Демон решает,  какой процесс получит доступ к файлу устройства.
