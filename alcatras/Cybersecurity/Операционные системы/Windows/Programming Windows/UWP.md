#### UWP - Universal Windows Platform
WinRT API - на нем основана UWP. Это позволяет коду выполняться на разных типах устройств.  WinRT единственная платформа для приложений на XBox.  Поскольку на XBox не особо часто используется что-то кроме игр -> UWP не то чтобы очень полезен.  WinRT дает языковые проекции, лучшую безопасность. В UWP другая модель приложений
1. Другое управление жизненным циклом приложения - оно полностью управляется системой. Когда пользователь сворачивает приложение система дает ему несколько секунд, чтобы сохранить свое состояние, после чего ему почти не дается ресурсов процессора.  Если большая нагрузка, то ОС вообще может завершить процесс. Это полезно для мобильных устройств, где пользователь постоянно переключается
2.  Приложение устанавливаются с помощью инсталлера - **MSIX** файлы, которые представляют из себя zip файл, содержащий бинарники, вместе с *манифестом*, который определяет, как они интегрируются в систему, например, там перечисляется, какие элементы требует приложение - например камера, микрофон и т.д
3.  Когда запускается обычная Win32 программа, она выполняется с правами того пользователя, который ее запустил.  Для UWP все иначе. Система создает временного виртуального пользователя с минимальными правами. Чтобы получить доступ к файлам, система обращается к специальному  WinRT API, который отправляет запрос в доверенный системный процесс - брокер.  Он доверяет только **явному согласию пользователя**, выраженному через системный UI.

Чтобы устранить недостатки UWP придумали *Windows App SDK*. Короче если вкратце, то он просто дает больше свободы, меньше ограничивает по безопасности и является более гибким в использовании5
