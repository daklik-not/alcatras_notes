#smss
NT ядро изначально запускает процесс smss.exe - самый первый пользовательский процесс. Он с помощью CreateProcess запускает crss.exe для Win32. Остальные создаются через CreateProcess.
Пройдемся по порядку
Процесс обращается к библиотекам подсистемы, которые нужны чтобы соединить процесс и ядро. Они реализуют функции специфичные для подсистемы. После обращения к библиотекам вызывается системный вызов CreateProcess, который перехватывается *run-time* библиотекой - это называется **хук**.  Далее вызывается ядро, которое с помощью LPC обращается в процессу подсистемы. Всем остальным занимается уже процесс подсистемы.  Также в самом ядре должна быть определенна поддержка подсистемы. Процессы подсистемы используют **нативные NT системные вызовы**
