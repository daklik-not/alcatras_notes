**Social Engineering** - термин, который используется для описания кибератак, где целью является человек. Обычный пример, когда сообщил код, мошеннику который представляется представителем, например, банка.
**Phishing** - вид social engineeringa. Он описывает тип мошенничества, когда скамер просит открыть пользователя веб-страницу, путем отправки имейла, сообщения и т.д.

| General fishing | Большие группы пользователей, например пользователи Amazon                         |
| --------------- | ---------------------------------------------------------------------------------- |
| Spearphishing   | Более нацеленная, небольшие группы людей, вроде группы работников в компании       |
| Whaling         | Нацеленная на 1 человека, направлена на индивидумов, особенно важных для компании. |
**Malware** - вредоносное ПО.
**Ransomware** - тип вредоносного ПО, которое блокирует данные жертвы или шифрует их, требуя выкуп за их восстановление.
Для того, чтобы сопротивляться ransomware необходимо немедленно отключить устройство от сети, дабы избежать заражения.  **[No More Ransom](https://www.nomoreransom.org/)** - крупнейший сайт с дешифраторами.
Cамое главное не платить выкуп.
**Password attack** - пароли каждого пользователя хранятся в виде кэша. Таким образом, даже слитая база данных сервиса не гарантирует хакерам доступ к аккаунтам всех пользователей. Однако они могут попробовать подобрать пароль, чтобы на выходе получился такой же кэш.
**Multi-Factor Authentication** - MFA, любой способ входа, в котором больше 1 ступени.
 **TOTP** - the particular second auntethication. Когда на второй стадии ввода требуется ручное вмешательство человека, какое-то действие. Самый яркий пример - код при логине в аккаунт, сейчас почти везде.
 Можно запомнить только 1 пароль, а не для всех сервисов. Для этого существует **Password manager**. Запоминаешь пароль для него, а он подставляет уже нужный во все сервисы.
 **TLS** - Transport Layer Security(шифровка трафика между сервером и пользователем).
 **Правило 321**
 Вы всегда должные хранить хотя бы 3 обновляемых копии своих данных.
 Бэкапы должны храниться хотя бы на 2 различных  видах хранителях, например в облаке и USB.
 Хотя бы 1 бэкап должен хранитсья внешне. Для этого отлично подойдут облака, например Гугл.
