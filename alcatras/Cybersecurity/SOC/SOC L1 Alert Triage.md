SOC видит миллионы логов каждый день. Чтобы среди них выделять опасные, используются специальные технологии

| Решение        | Описание                                                                                                                                                                                                                                                   | Примеры            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| *SIEM* системы | Система, которая позволяет собирать информацию для SOC аналитиков, в виде логов, алертов, артефактов на централизированной платформе.<br>Идеальный выбор для большинства команд                                                                            | Splunk ES          |
| EDR, NDR       | Смотрит алерты именно на конечных устройства. Например, если пользовательская программа начинает шифровать диск - EDR просто прекратит ее выполнение                                                                                                       | Microsoft Defender |
| SOAR системы   | Это решение, которое помогает организациям оптимизировать и автоматизировать security операции - например реагирование на уязвимость                                                                                                                       | Splunk Soar        |
| ITSM           | Насколько я понимаю, она нужна, чтобы разные IT отделы могли взаимодействовать между собой. Например, SOAR говорит, что надо обновить версию Apache, чтобы избежать HTTP2 бомбы, тогда SOAR кладет тикет в ITSM, и потом системный администратор обновляет | Jira               |

У алертов есть свойства - реализация отличается от инструмента к инструменту. 
1. Время создание алерта(обычно несколько минут после триггера)
2. Имя алерта - саммари того, что случилось
3. Значимость алерта. Устанавливается автоматически, SOC аналитик может менять
4. Статус алерта - показывает в работе/завершен/новый
5. Вердикт алерта - угроза/не угроза
6. Alert Assignee - показывает аналитика, который в текущий момент работает надо проблемой.
7. Чем был вызван алерт
8. Детали алерта(значения на которых был вызван триггер) + комментарии самого SOC аналитика.
