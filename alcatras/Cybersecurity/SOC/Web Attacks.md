#### Client-Side атаки
Фактически просто невозможно для SOC аналитика обнаружить client-side атаку, просто потому, что она происходит на стороне клиента - в его браузере. 
1. XSS
2. CSRF #csrf
3. Clickjacking - невидимые элементы, на которые пользователь случайно нажимает
   
#### Server-Side
Здесь проще, потому что каждый веб-запрос записывается в логах.
1. Brute-force
2. SQLi #sqli
3. Command Injection. Когда системе передается плохой пользовательский ввод
Пример логов на картинке. Здесь сначала с помощью фаззера директорий(типо dirbuster), подбирается директория. Затем c помощью Hydra делается брут-форс на пароль. Далее с помощью sqlmap делаются sql иньекции.

#### Web Shell
Веб-шелл это вредоносная программка, загружаемая на веб-сервер.  Используется для *initial access* и *persistence*.  Веб-шеллы бывают очень разные. Например, параметры для выполнения можно передавать прямо в GET, а можно в POST форме. 
![[Pasted image 20260716183423.png]]
Чтобы обнаружить веб-шелл нужно смотреть логи веб-сервера.
Индикаторы:
1.  Частые GET запросы - атакующий ищет место, куда загрузить шелл
2. POST запросы к местам, куда можно загружать файлы
3. Повторяющиеся запросы к одному и тому же файлу
4. Подозрительные User-Agent и IP адреса. 
5. Части URL, которые связаны с параметром, типо *example.php?query=somequery*
6. Отсутствие Referrer.

Также нужно настроить audit-d - специальная Linux утилита, в которой можно настроить правила.  Она отслеживает активность в системе. Нужно комбинировать данные оттуда и данные из логов веб-сервера

Нужно смотреть файлы в файловой системе.  Чаще всего создается либо сюда *Apache: `/var/www/html/`* либо сюда Nginx: `/usr/share/nginx/html/`
Нужно проверять подозрительные файлы - .*php, .jsp* а также искать двойные расширения вроде *image.jpg.php*.  
Полезные команды"
```c
find /var/www -type f -name "*.php" -newerct "2025-07-01" ! -newerct "2025-08-01" // эта команда ищет php файлы, которые были изменены в заданные период
grep -r "eval(" wp-content // ищем подозрительные строки в файлах, вроде eval
```
