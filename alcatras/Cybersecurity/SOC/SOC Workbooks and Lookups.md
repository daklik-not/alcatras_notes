Чтобы понять, является ли алерт реально опасным, нужно понять контекст ситуации.
Можно использовать 2 следующие информации
***Identity inventory*** - реестр учетных данных. Он содержит данные о работниках, машинах, и т.д Примеры:
1. Active directory - база данных учетных данных  - Microsoft AD
2. SSO providers - то же база учетных данных, но в облаке - Okta
3. HR Systems - данные о работниках
4. Custom Solution - собственные решения

***Asset Inventory*** - реестр вычислительных устройств. Он содержит данные именно о устройствах
![[Pasted image 20260607121252.png]]
Примеры:
1. Active Directory
2. SIEM, EDR - некоторые SIEM системы собирают информацию о устройствах через агентов, установленных на устройствах
3. MDM Solution - специализированные системы управления мобильными устройствами и компьютерами. Позволяет управлять действиями на самом устройстве.
4. Custom
