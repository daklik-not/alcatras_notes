Насколько я понял это современная замена классическому netcat, поэтому учить netcat не очень много смысла.
У **ncat** есть 2 режима:
1. *connect mode* - когда подключаемся к чему-то, что слушает
2. *listen mode* - наоборот ждем пока кто-то обратиться 

**Short overview**
```c
ncat --listen host port // listen mode
ncat host port // connect mode'
**ncat -l localhost 8080 < hello.http** // слушать на локалхосте, при запросе отвечать страницей. Если обновить страницу, то оно не сработает - ввод заканчивается
--udp, --sctp // использовать UDP вместо TCP
-4, -6 // использовать только IPV4/IPV6
```
Если у listen опустить порт, то он будет просто слушать на всех локальных интерфейсах. Стандартное соединение - TCP. Стандартный порт, на котором слушает *ncaat* - 31337.

***Brokering***
Смысл в том, что сервер слушает, и когда ему что то приходит он отправляет это на все установленные соединения.
```c
--broker --listen
```
