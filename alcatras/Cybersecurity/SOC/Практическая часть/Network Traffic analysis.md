Внутри корпоративной сети есть несколько потоков сети и источников.
Источники можно сгруппировать, как 
1. *Intermediary* - файрволлы, коммутаторы, веб-прокси, IDS, IPS,  роутеры и т.д. Кстати, говоря IDS - смотрит содержимое пакета и уведомляет о том, что оно вероятно вредоносное. IPS - смотрит содержимое пакета и блокирует или сбрасывает соединение. Файрволл в свою очередь смотрит только на хэдеры.
	1. *Endpoint* - сервера, хосты, устройства, принтеры, телефоны.

Потоки можно сгруппировать, как *North-South - трафик LAN, проходящий через firewall*, *East-West - трафик между устройствами в LAN*.

#### Nmap Filtering
Фильтр на TCP Connect Scan
```c
tcp.flags.syn==1 and tcp.flags.ack==0 and tcp.window_size > 1024
```
Фильтр на TCP Syn Scan
```c
tcp.flags.syn==1 and tcp.flags.ack==0 and tcp.window_size <= 1024
```
Фильтр на неоткрытие UDP соединения
```c
icmp.type==3 and icmp.code==3`
```
#### ARP analysis
Есть ARP Spoofing - 1 устройство выдает себя за другое в локальной сети. Есть ARP Flooding - 1 устройство начинает спамить ARP запросами, чтобы забить кэш или добиться DoS. В целом нужно просто смотреть трафик и искать что-то подозрительное.
```
arp.opcode == 1 - ARP запрос
arp.opcode == 0 - ARP ответ
```

#### Туннелирование
Туннелирование или проброс портов позволяет защищенно общаться между внешней сеть и приватной.
___
Чуть чуть про туннелирование. Короче говоря оно позволяет общаться устройствам в 2 разных локальных сетях. В первое тело мы кладем адрес хоста назначения в его локальной сети. Потом этот запрос инкапсулируется в другой запрос, который содержит уже адрес шлюза хоста назначения в глобальной сети.  Шлюз хоста назначения смотрит протокол, понимает что это туннелированный трафик, отбрасывает внешний заголовок и уже смотрит внутренний. Шифрованный туннель, это когда внутренний пакет полностью зашифрован
____
Однако в то же время оно позволяет злоумышленникам безопасно покидать защищенный периметр

***ICMP***
ICMP туннелирование используется для эксфильтрации данных.  Признаком такой эксфильтрации является большой размер пересылаемого ICMP трафика.
#### DNS
DNS трафик часто игнорируется. В теле DNS запроса часто передают C2 команды. Чаще всего это выглядит примерно так
```c
**encoded-commands.maliciousdomain.com**
```
Признаки - большая длина DNS запроса, dnscat,
```c
- `dns.qry.name.len > 15 and !mdns`
  //mdns - когда устроойства находят друг друга без выделенного DNS сервера
  - `dns contains "dnscat"`
```

#### FTP
Аналогично DHCP - надо когда-нибудь изучить его нормально. Пока так.
```c
|Команда|Назначение|Пример|
|USER|Отправить логин|USER vasya|
|PASS|Отправить пароль|PASS 12345|
|QUIT|Закрыть соединение|QUIT|
|PWD|Показать текущую папку на сервере|PWD|
|CWD|Перейти в другую папку|CWD /public/html|
|CDUP|Перейти в родительскую папку|CDUP|
|LIST|Показать содержимое текущей папки (файлы и подпапки)|LIST|
|RETR|Скачать файл с сервера|RETR photo.jpg|
|STOR|Загрузить файл на сервер|STOR archive.zip|
|DELE|Удалить файл с сервера|DELE old.txt|
|MKD|Создать новую папку|MKD new_folder|
|RMD|Удалить пустую папку|RMD empty_folder|
|RNFR / RNTO|Переименовать файл или папку (сначала старое имя, потом новое)|RNFR old.txt → RNTO new.txt|
|TYPE|Установить режим передачи: I – бинарный, A – текстовый (ASCII)|TYPE I (обязательно перед загрузкой картинок, архивов)|
|PASV|Включить пассивный режим (нужен, если вы за файрволом)|PASV|
|PORT|Включить активный режим (сервер сам подключается к вам)|PORT 192,168,1,10,4,1|
|REST|Возобновить скачивание/загрузку с указанного байта|REST 1024 (затем RETR или STOR)|
```
Здесь ничего особенного нет, просто надо смотреть на поля, команды и анализировать это.

#### TLS
Чаще всего трафик шифруются. Нужно уметь с помощью Wireshark дешифровать трафик
```c
- - Client Hello: (http.request or tls.handshake.type == 1) and !(ssdp)
- - Server Hello: (http.request or tls.handshake.type == 2) and !(ssdp)
```

### NetworkMiner
Это что то похожее на Wireshark. На Reddit пишут, что wireshark идеален для анализа пакетов, в то время, как NetworkMiner хорош для автоматического выделения файлов и писем.
```c
Either way, after you've narrowed it down, now you'd run it through Network Miner to carve out the actual artifacts - all of the HTML pages, the images, and code, etc.
```
То есть непосредственно выделять сетевые артефакты. 
Лучше не использовать network miner для захвата трафика, а только для его анализа. К тому же сниффер доступен только на Windows.
