Это концептуальная модель, разработанная *Lockheed Martin*, которая классифицирует шаги любой кибер-атаки.
**Reconnaissance  - разведка**
Сбор данных для атаки. Важный навык - *OSINT*.  Есть пассивная разведка - к ней как раз относится OSINT, а есть активная разведка - социальная инженерия, скан портов и так далее.
**Weaponization - вооружение**
Можно сгенерировать, можно купить, можно разработать самому.
*Malware* - софт, который разработан нанести урон, получить доступ к устройству
*Exploit* - программы или код, которые используют уязвимости в приложении или  системе
*Payload* - вредоносный код, который запускается на системе.
**Delivery - передача эксплойта на цель**
Можно с помощью фишинга, флешки оставленной в публичном месте, *watering hole атака*. Про последнюю, это когда злоумышленник нацеливается на группу людей, которая посещает 1 и тот же сайт, и с помощью какой-то рекламы или баннера заставляет их перейти на другой сайт, откуда скачивается малварь.
**Exploitation - момент выполнения кода на цели**
Признаки эксплуатации - появился странный процесс, создаются новые сервисы, изменениея в реестре, подозрительные команды в командной строке.
**Installation**
Когда злоумышленник получил доступ к машине, он хочет создать бэкдор. Более того, бэкдор должен быть персистентным. Есть несколько вариантов.
1. Установить веб-шелл на сервер. Веб-сервер это скрипт, написанный на языках веб-разработки и используемый атакующим для получения доступа к системе.
2. Установить бэкдор на машину атакуемого. Например *Meterpreter* - он дает интерактивные шелл и позволяет выполнять удаленные команды
3. Создание или модификация Windows сервисов - T1543.003 в MITRE ATT&CK.  Windows сервисы это такие процессы демоны, который занимается разными системными задачами, вроде обновлений. Злоумышленник может сделать так, что новый сервис, созданный им, будет запускаться при старте системы - персистентность + сервисы имеют SYSTEM статус.
4. Создать run-key c вредосносным пэйлоадом. Run-key позволяет запускать все программы, которые в них прописаны. Сами ключи где-то здесь - HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run.

На этой фазе используется *TimeStompic фаза*.

**Command and Control**
После установление бэкдора запускается C2 канал. Стандартные C2 каналы используют - HTTP на 80 порту и HTTPS на 443 - нормальный трафик мешается с плохим. Или можно сделать, чтобы инфицированная машина отправляла запросы на DNS сервер, принадлежащий атакующему.
