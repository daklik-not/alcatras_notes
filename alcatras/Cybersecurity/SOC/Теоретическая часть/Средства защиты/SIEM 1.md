***Windows Machine***
Windows логи берутся из Event Viewer'а. 
***Linux machine***
*/var/log/httpd* - содержит HTTP запросы, ответы и логи ошибок
/var/log/cron - события, относящиеся к *cron* работе
*var/log/auth/log* и */var/log/secure*  - логи всего, что связано с аутентификацией.
*/var/log/kern* - содержит события, связанные с ядром
***Web Server***
Зависит от реализации. Например, логи Apache падают в */var/log/apache* или */var/log/httpd*


Логи доставляются до центральной части также по разному.
1. *Agent* - софт на эндпоинте, который отправляет все важные логи на SIEM сервер
2. *Syslog*  - сетевой протокол прикладного уровня для сбора данных с различных систем - веб-серверов, баз данных. Он стандартизирует формат сообщения от эндпоинтов и шлет с них логи на веб-сервер.
3. *Manual Upload*. Загрузить файл с логами оффлайн.
4. *Port-Forwarding* - все данные с предыдущего хоста отсылаются на SIEM.
   
#### Splunc
Мировой стандарт(не российский) SIEM.
Есть 3 главных компонента - *Indexer*, *Search Head*, *Forwarder*
*Splunk forwarder* - это агент, который собирает данные и отправляет их на Splunk - например, трафик веб-сервера, запросы к БД.
*Splunk Indexer*  - обрабатывает данные, полученные от форвардеров. Он парсит и нормализует данные в field-value пары, выдает категории, и сохраняет все в виде событий.
*Search Head* - с помощью него ищем индексированные логи. Когда пользователь выполняет поиск, запрос отсылается на индексер и все возвращется в виде *field-value*.

#### ELK
ELK не является классической SIEM, однако используется, как она. Он состоит из нескольких компонентов. Кстати, вроде используется в МТС))
1. *Elasticsearch* - поисковой и аналитический движок для JSON документов
2. *Logstash*  - обрабатывает данные, фильтрует и нормализует их. Поскольку парсинг, например с помощью регулярных выражений, достаточно тяжелая вещь, то как правило хостится на отдельном сервере. Файл конфигурации содержит *Input* - источник с которого будут получены данные, *Filter - фильтрация логов для их нормализации*, *Output*- куда отправлять данные.
3. *Beats* - работают, как агенты на хостах - отправляют данные на *ElasticSearch*
4. *Kibana* - web-based визуализация данных.'
