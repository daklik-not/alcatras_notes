Security Orchestration, Automation, and Response. Поскольку даже с использованием SIEM логов может быть очень много - логи приходят от EDR,  от файрволла напрямую. Можно управлять всем вместе через *SOAR* интерфейс.
У SOAR есть несколько главных преимуществ:
*Оркестрация*
Рассмотрим пример без SOAR - VPN brutforce
1. SIEM проверяет, стандартный ли ли этот IP для пользователя, при его авторизации
2. *Thret Intelligence(TI)*  подтверждает репутацию IP
3. *IAM(Identity and Access Managemen)* - отключает пользователя, если была удачная попытка
4. *Ticketing System* для открытия и отслеживания инцидента
Переключаться между инструментами долго. Для множества стандартных паттернов атаки у *SOAR* есть *playbooks*. *SOAR* действует строго по ним. Действия в плейбуках могут быть автоматизированы. Таким образом *SOAR* система может без SOC аналитика самостоятельно отрабатывать все. Однако у *SOAR* проблемы с комплексными результатами.
