Нужна какая-то безопасность для уже установленных соединений, не отклоненных файрволлом. Для этих целей и нужен IDS. Он мониторит трафик, основываясь на сигнатурах и аномалиях, и, обнаружив странный трафик, вызывает алерты.
Есть HIDS - которые устанавливаются на каждое устройство отдельно, а есть NIDS, который просто смотрит весь трафик в сети.

***Режимы обнаружения***
1. Signature-Based IDS. Это когда для каждой недавней атаки хранится сигнатура. Чем больше сигнатур тем лучше работает. Не может распознавать *zero-day* атаки.
2. Anomaly-Based IDS.  Этот тип IDS  смотрит на нормальное поведение сети, и если оно начинает себя вести ненормально, то вызывает алерт. Проблема таких IDS в том, что много ложных алертов. Но их можно уменьшить если вручную настроить IDS
3. Гибридная

IDS просто пассивно смотрит - NIDS и HIDS.

 IPS  активно защищает, а именно предотвращает подозрительные события.
  Есть NIPS, который смотрит трафик из различных подсетей, если обнаруживает сигнатуру, то просто обрывает соединение. 
  Есть NBA -  Network Behavior Analysis.  Она смотрит на поведение.  Отличие от NIPS в том, что он требует периода обучения - но действует значительно более эффективно.  Во время периода тренировок очевидно много сложных срабатываний.  
  Есть WIPS который предотвращает беспроводные атаки
  Есть HIPS, который  защищает трафик с конкретной точки, тоже работает на сигнатурах. 

Есть 3 типа обнаружения и предотвращения
1. *Signature based* - правила, которые идентифицируют 
2. *Behaviour-Based* - смотрит новые паттерны, которые прошли сигнатурные проверки
3. Policy-based -  обнаруживает активности,  согласно системным конфигурациям,  и политик безопасности

Одна из самых популярных IDS - Snort.  У нее есть 3 режима
1. Packet Sniffer mode - просто сниффер пакетов.
2. Packet logging mode - сохраняет весь трафик в PCAP файл.
3. Network Intruison detection system - мониторит весь трафик в режиме реального времени и применяет правила
