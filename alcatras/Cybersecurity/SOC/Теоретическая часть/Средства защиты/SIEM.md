**SIEM** - Security Information and Event Management system. Для SOC - ключевое решение.
Устройства в сети генерируют логи. Эти логи используются для анализа. 
Есть 2 типа логов:
1. Host-Centric Log Sources. То, что происходит внутри хостов. Например, запуск процесса, пользователь, который пытается аутентифицироваться.
2. Network-Centric Log Sources. Когда 2 хоста взаимодействуют между собой. Логи генерируют файрволлы, роутеры и т.д. Например, SSH соединение, веб-трафик и т.д.
