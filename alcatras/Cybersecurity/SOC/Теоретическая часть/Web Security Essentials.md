Сейчас очень большой тренд на веб-приложения - это просто удобнее, чем для каждого приложения скачивать хост на устройство. Однако веб-приложения являются уязвимыми для атаки поскольку взаимодействуют с бэкэнд системами.
#### Компоненты веб-сервиса
1. Приложение.
2. Веб-сервер.  Самые часто используемые - Apache для простых веб-сайтов и блогов, Nginx - стандарт для высоконагруженных серверов,  IIS - используется в *enterprise*.  Сейчас чаще всего веб-сервер выступает в роли прокси между клиентом и *application* сервером. Однако веб-сервер раздает статику, которая не требует логики, вроде скриптов или картинок, а также занимается дешифрованием TLS
3. Операционная система, которая запустила сервер , на которой запущено само приложение

#### Защита
1.  Защита приложений.  Правильная обработка ошибок,  валидация пользовательского ввода - защита от инъекций, ограничение доступа согласно ролям
2. Защита веб-сервера.  Логирование, WAF, CDN( #cdn). 
3.  Антивирусы, останавливать ненужные сервисы и закрывать неиспользуемые порты, использовать низкие привилегии для пользователей

Помимо #CDN WAF является хорошим средством. В реальности WAF это тот же firewall но для HTTP трафика, которые блокирует подозрительные HTTP запросы. Есть несколько типов WAF. 
1. Cloud-based(Reverse-Proxy) - сидит перед веб-сервером, перед локальной сетью.
2. Host-based - напрямую на веб-сервере
3. Network-Based - сидит в локальной сети, передает нормальный трафик на веб-сервер. 

WAF определяет по:
1. Сигнатурам, например sqlmap/1.8.1
2. Контекст и поведение запросов
3. Отклонение от нормального поведения трафика 
4. Местоположение -> IP пользователей
