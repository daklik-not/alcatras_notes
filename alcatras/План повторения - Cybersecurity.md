## Как работать с планом

Этот план — не список для вычитки, а **маршрут для воспоминания**. Ты уже прошёл эти темы. Теперь задача — закрепить.

### 🕐 Тайминг на каждый день

| Этап | Время |
|------|-------|
| **Warm-up** — открой заметку, пробегись глазами по заголовкам | 2 мин |
| **Recall** — закрой заметку и перескажи себе (вслух или в голове) всё, что помнишь | 3-5 мин |
| **Check** — открой, сверь, что упустил | 2-4 мин |
| **Повтори для след. заметки** | |
| **Итого:** 3-4 заметки | **~35 мин** |
| **Итоговый recall** — прокрути в голове связку: «что я сегодня повторил(а) и как это связано» | **~5-7 мин** |

**Важно:** Не пытайся охватить все детали. Цель — активировать нейронные связи, а не перечитать всё слово в слово.
